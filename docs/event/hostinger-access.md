## How to access free Hostinger services

1. Visit Hostinger booth to get a dedicated coupon code for your team.
2. Go to [https://www.hostinger.com/applications/hermes-agent](https://www.hostinger.com/applications/hermes-agent)
3. Select the KVM 2 plan.
4. In the Cart, select the KVM 2 plan for 1 month, select "5000 Hostinger AI Credits," and check-mark "Instant web scraping".
5. On the right side, instead of "JUNCTION-1" apply the Coupon code dedicated to your team which you got from the Hostinger booth.
6. Click Continue to start setting up your VPS. You'll see the "Setting up your Hermes Agent" screen. This is your team's VPS being created, with Hermes Agent preinstalled in case you want it. It takes about 5 minutes. You can leave the page, and we'll email you when it's ready.
7. When setup finishes, open your VPS. The setup screen switches to your VPS overview, or you can click the link in the email. You can also find it any time in hPanel under VPS in the left menu. You get full root access and Docker.
8. Get your AI Router API key. AI Router gives you one API key for 150+ AI models (Claude, GPT, DeepSeek, Mistral and more), paid from the 5000 Hostinger AI credits you added in step 4. The key is OpenAI and Anthropic compatible, so it works with any OpenAI SDK.

   Are you building an app that uses AI models? Use this key in your codebase too. One key covers every model, so you can switch between them without signing up anywhere else.
9. Build your project on the VPS, whichever way you like.
   - Your own tools. SSH in, use Docker, or connect Claude Code, Cursor or VS Code with the Hostinger Connector (you can find instructions how to connect with coding agents n the hPanel page API) and deploy from your editor.
   - Hermes Agent (optional). It's already installed on your VPS and runs on your AI credits. Open it, describe what you want, and it writes the code and deploys it for you.
10. Optional. Make a showcase website with AI Builder. In your Hostinger panel, go to Websites and click "Get websites plan".
11. Use the same dedicated coupon code for Unlimited plan (1 month), add a Website, and start building - either by vibe coding or setting up manually with the drag-and-drop editor.
