# Probes

Linear probes on the vectors of the X corpus: what they detect, how their labels were made, how they were trained and what they measure.

| File | What it holds |
| --- | --- |
| [`report.md`](report.md) | The method and the results, with figures. Start here |
| [`taxonomy.md`](taxonomy.md) | The 63 labels, by family, and what each one is for |
| [`guides/`](guides/) | The exact instructions given to annotators: `common.md`, then one guide per annotation pass |
| [`journal.md`](journal.md) | What was run, in order, with what it gave and what was decided |
| [`figures/`](figures/) | The figures of the report |

Code: `pipelines/probes/`. Data and labels: `data/probes/` (git-ignored: the corpus states no licence, so no post and no label is committed). Numbers: `reports/probes/metrics.json`.
